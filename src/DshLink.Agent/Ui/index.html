DSH 插件

把服务器插件指向本 Agent。这里生成可直接复制的安装命令和配置。

连接参数

Agent token
服务器侧 baseUrl
先在「隧道」页确认 remote Agent 端口（默认 18765），并把插件装到服务器。插件只依赖这个 baseUrl 和 token。

服务器安装命令

dsh plugin --profile web add link:/opt/dsh-board-link
把下载的 ZIP 解压到上面的服务器目录，再执行命令。
